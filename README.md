#  Redux Todo App (React + Vite)
A simple yet powerful Todo List application built with React, Vite, and Redux Toolkit.  
This project demonstrates modern state management, async thunks, and reducer design.  
It’s designed to showcase clean architecture, practical productivity features, and AI‑powered task suggestions.

---

##  Tech Stack
- **Frontend:** React + Vite  
- **State Management:** Redux Toolkit  
- **Language:** JavaScript   
- **Styling:** CSS (custom classes)  
- **Version Control:** Git & GitHub  

---
##  Setup Instructions
1. Clone the repository:
   ```bash
   git clone https://github.com/your-username/redux-class.git
   cd redux-class
2. Install dependencies:
  bash
  npm install
3. Run the development server:
   npm run dev
4. Open your browser at http://localhost:5173.

##  Features
  Add, edit, and delete todos
  Mark tasks as complete/incomplete
  AI‑powered task suggestions

  scalability
